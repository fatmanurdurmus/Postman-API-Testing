# Postman-API-Testing
Demonstration of API testing using Postman with the RESTful Booker sample API.


## 🇹🇷 

Bu proje, **Postman** aracıyla API testlerinin nasıl yapıldığını göstermek amacıyla hazırlanmıştır.  
Videoda, [RESTful Booker](https://documenter.getpostman.com/view/4805376/RznFoxY8) örnek API’si kullanılarak **GET, POST, PUT, PATCH ve DELETE** istekleri adım adım incelenmiştir.  
Her çağrının nasıl gönderildiği, gelen yanıtların nasıl yorumlandığı ve testlerin nasıl çalıştığı anlatılmıştır.

### Amaç
- API test araçlarından **Postman**’i tanıtmak  
- **REST API metodlarını** (GET, POST, PUT, PATCH, DELETE) örneklerle açıklamak  
- İstek ve yanıt yapısını, test senaryolarını ve hata durumlarını göstermek  

### İçerik
- Postman arayüzü tanıtımı  
- Collection ve environment oluşturma  
- RESTful Booker API’leri üzerinden istek gönderme  
- Authorization (Basic Auth, Token) kullanımı  
- Test script örnekleriyle doğrulama  
- Response kodlarının incelenmesi

## 🇬🇧 

This project demonstrates how to perform API testing using **Postman**.  
In the video, we used the [RESTful Booker](https://documenter.getpostman.com/view/4805376/RznFoxY8) sample API to explain each HTTP method — **GET, POST, PUT, PATCH, and DELETE** — step by step.  
The video also covers how to interpret responses and how to write simple test scripts.

### Purpose
- Introduce **Postman** as an API testing tool  
- Explain **REST API methods** (GET, POST, PUT, PATCH, DELETE) with real examples  
- Show how to structure requests, handle responses, and add test cases  

### Content
- Overview of the Postman interface  
- Creating a collection and environment  
- Sending requests via RESTful Booker APIs  
- Using Authorization (Basic Auth, Token)  
- Writing simple test scripts  
- Analyzing response codes
